Repositório dedicado ao domínio da lógica de programação e fundamentos de algoritmos utilizando o VisualG. Desenvolvo soluções estruturadas passo a passo, abordando fluxos de controle, laços de repetição e estruturas de dados para resolver desafios fundamentais de lógica.

---

### 🛠️ Conceitos Abordados

* **Operações Básicas e Entrada/Saída:** Manipulação de variáveis, operadores aritméticos, leitura e escrita de dados.
* **Cálculos e Fórmulas:** Porcentagem, médias ponderadas, conversão de unidades e equações matemáticas aplicadas.
* **Estruturas Condicionais Simples e Compostas:** Tomada de decisão utilizando `se ... entao ... senao`.
* **Estruturas Condicionais Aninhadas:** Encadeamento de condições para resolução de problemas com múltiplas regras de negócio.
* **Operadores Relacionais:** Comparação de valores (`>`, `<`, `>=`, `<=`, `=`, `<>`).
* **Operadores Lógicos:** Construção de expressões complexas utilizando `e`, `ou`, `nao` e `xou`.
* **Análise de Algoritmos e Teste de Mesa:** Rastreamento manual de variáveis e validação de lógica de código.
